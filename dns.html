Domain Name Server (DNS)

A Domain Name Server (DNS) is a hierarchical system that translates human-readable domain names (like www.example.com) into IP addresses (like 93.184.216.34).

Functions of DNS:

  • Resolves domain names to IP addresses
  • Facilitates internet navigation
  • Supports email routing and other services
