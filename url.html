Uniform Resource Locators (URL)

A URL is a string of characters that specifies the location of a resource on the internet.

Components of a URL:

  • Scheme: Indicates the protocol (e.g., http, https, ftp)
  • Host: The domain name or IP address of the server
  • Port: Optional, specifies the port number (default is 80 for HTTP)
  • Path: The specific resource on the server (e.g., /index.html)
  • Query: Optional, provides additional parameters (e.g., ?id=123)
  • Fragment: Optional, points to a specific section of the resource (e.g., #section1)
