Web 1.0

Web 1.0 refers to the early days of the World Wide Web, characterized by static web pages and limited user interaction.

Key Features of Web 1.0:

  • Static web pages with limited interactivity
  • Content created and controlled by website owners
  • Limited user-generated content and social interaction
