Web Browser

The World Wide Web is a system of interlinked documents and resources accessed over the Internet using web browsers. It is not the Internet itself, but a service that runs on top of it.

Role of Web Browsers:

  • Enables access to websites, multimedia, and web applications
  • Uses HTTP/HTTPS protocols
  • Connects users to information globally
