HyperText Transfer Protocol (HTTP)

HTTP is the foundation of data communication for the World Wide Web. It is a client-server protocol, where clients (like web browsers) request resources from servers (like web servers).

Functions of HTTP:

  • Enables communication between web browsers and web servers
  • Supports the transfer of HTML pages and other resources
  • Provides a simple request-response mechanism
