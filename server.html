Web Server

A web server is a computer system that processes requests from web clients and delivers web pages and other content over the internet or an intranet.

Functions of a Web Server:

  • Handles HTTP requests and responses
  • Serves static and dynamic content
  • Manages security and access control
  • Supports server-side scripting and applications
